# Silica Capability Scan (Silicore-C)

Silicore-C provides three capability lanes:
- Profile: username and identity presence across platforms
- Surface: domain surface enumeration and security signal capture
- Fusion: correlation of profile and surface intelligence

Supporting Capabilities
- plugin ABI for enrichment and scoring
- filter ABI for pipeline-level prioritization
- manifest validation and schema checks
- consistent report outputs for automation
