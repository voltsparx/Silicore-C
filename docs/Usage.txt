Silicore-C v1.0 (Crystal Lattice)

Usage
  silicore-c profile <username...> [flags]
  silicore-c surface <domain...> [flags]
  silicore-c fusion <username> <domain> [flags]
  silicore-c orchestrate <profile|surface|fusion> <target> [flags]
  silicore-c quicktest [--template id | --list-templates] [--seed n] [--json]
  silicore-c wizard [--profile-phase|--surface-phase|--fusion-phase] [--usernames u1,u2] [--domain example.com] [--sync-modules]
  silicore-c plugins | filters | modules | history | keywords
  silicore-c anonymity [--tor|--no-tor] [--proxy url] [--check|--prompt]
  silicore-c live <target> [--port n] [--no-browser]
  silicore-c prompt
  silicore-c help
  silicore-c show plugins
  silicore-c show filters
  silicore-c show platforms
  silicore-c show modules

Flags
  --preset fast|quick|balanced|deep|max
  --profile-preset fast|quick|balanced|deep|max
  --surface-preset quick|balanced|deep
  --profile <preset>
  --timeout <seconds>
  --concurrency <n> --max-concurrency <n> --max-workers <n>
  --max-platforms <n> --min-confidence <n>
  --secondary-target <domain> --source-profile
  --proxy <url>
  --no-proxy
  --tor
  --no-tor
  --json --html --csv --no-csv
  --out <dir>
  --plugin a,b
  --plugins a,b
  --all-plugins
  --filter a,b
  --filters a,b
  --all-filters
  --extension-control auto|manual|hybrid
  --list-plugins --list-filters --list-modules
  --scope <id> --kind <id> --framework <id> --tag <id> --search <text> --limit <n> --stats-only
  --ct | --no-ct
  --rdap | --no-rdap
  --max-subdomains <n>
  --live --no-browser --port <n> --live-port <n>
  --list-templates --template <id> --seed <n>
  --usernames <u1,u2> --domain <domain> --sync-modules

Live Reports
  --live starts a local report server (default port 7331 unless --live-port is set).
  In non-prompt runs, Silicore-C waits for Enter before shutting the live server down.

Prompt Mode
Run silicore-c with no arguments to enter prompt mode. It will ask for:
  1. workflow and target
  2. output formats (comma-separated)
  3. output directory
Defaults are txt and the current working directory.

Tor Routing
  --tor enables Tor routing via socks5h://127.0.0.1:9050.
  If Tor is already running, Silicore-C uses it.
  If Tor is not running, Silicore-C asks to auto-install, configure, and start Tor.

Examples
  silicore-c profile alice --preset deep --json --out output
  silicore-c surface example.com --html --json
  silicore-c fusion alice example.com --all-plugins --all-filters
